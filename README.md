## Installation

**Rooted (LSPosed)**
1. Download & install the APK
2. Enable in LSPosed and select your keyboard
3. Restart keyboard

**Non-Rooted (LSPatch)**
1. Patch your keyboard with LSPatch
2. Install patched keyboard + KGPT
3. Configure & enjoy
